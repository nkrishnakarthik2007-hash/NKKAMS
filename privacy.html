Privacy notice

Last updated: 16 November 2026

NKKAMS is an early-stage attendance management project. This notice explains, at a high level, what information the public website and organisation access request form are designed to collect.

Public demo

The public demo uses fictional sample names, employee IDs and attendance records. It is a read-only demonstration and is not connected to a real organisation's attendance data.

Organisation access requests

If you submit an organisation access request, the form collects the organisation name, contact person's name, organisation type, location, approximate member count, contact details and the intended use you provide. These details are used to review and respond to the request. Submitting a request does not automatically create an organisation or grant access.

Authenticated workspaces

Real workspace information is intended to be available only to authenticated users with appropriate permissions. Organisation-level access controls are part of the application design. Do not submit sensitive personal information through a demo or public request form.

Data handling and contact

This project is still being developed. Before using NKKAMS for operational or sensitive records, an organisation should review its data handling requirements and obtain any necessary assurances from the project maintainer. For questions about an access request, return to the NKKAMS access request page and provide a contact method.

Changes

This notice may be updated as the project develops. The latest version will be published on this page.
